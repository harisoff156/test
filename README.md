# Škoda Octavia A7 RS — лендинг

Одностраничный лендинг для продажи Škoda Octavia A7 RS. Чистый HTML/CSS/JS без сборщиков и зависимостей.

## Файлы

- `index.html` — разметка страницы (hero, характеристики, галерея, преимущества, форма связи).
- `styles.css` — оформление, тёмная тема в фирменных RS-зелёных акцентах, адаптив под мобильные.
- `script.js` — анимации появления секций, маска телефона, валидация и имитация отправки формы.

## Как открыть

```bash
# из любого статического сервера, например:
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Либо просто открыть `index.html` двойным кликом в браузере.

## Что заменить перед публикацией

- Контактные данные (`tel:`, `mailto:`, адрес) в секции «Контакты».
- Цену, год, пробег и описание комплектации — в hero-секции.
- Реальные фотографии вместо CSS-плейсхолдеров (поменять в `.gallery-photo--*`).
- Ссылку обработчика формы — сейчас отправка имитируется в `script.js`.
